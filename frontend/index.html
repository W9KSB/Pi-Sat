External DATA Decode

Disabled

External DATA Decode uses the IC-9700's IF output instead of its normal filtered AF audio. Select FM or USB (upper sideband) to match the transmission. While enabled, Pi-Sat selects SUB FM-DATA/FIL1 or USB-DATA/FIL1, software-demodulates the IF stream, and sends 48 kHz mono audio to the external Windows client. Disable streaming before changing demodulation.

Normal Pi-Sat receive audio is temporarily replaced by this data path. Disabling External DATA Decode restores normal AF audio operation.
